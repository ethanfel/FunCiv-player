# First working implementation — 21 September 2026

Repository: [ethanfel/FunCiv-player](https://github.com/ethanfel/FunCiv-player), forked from FunSync revision `147a788f55ff762b126abcd63d11b52996bdf1ad`.

The implemented slice is a desktop Composer with real song import/analysis, editable sections, category-tagged clips, deterministic arrangements, live audio/video preview, a six-axis motion compiler, device-source binding, persisted recipes, selected remote-asset resolution, and disposable MP4/script rendering. It runs alongside the original player with independent settings and backend ownership.

## Deliberate differences from the original plan

**Civitai source filters — 24 September 2026.** Dataset refresh now imports `creator_username`, `post_id` and an allowlisted `civitai_metadata` object. Dimensions, dates, model/version IDs, content rating and reaction counts are validated; public page links are reconstructed from supported site names and identifiers. These fields never become local media paths or change verified scripts, personal ratings or asset bindings. The newest current metadata record is shared across linked video variants; cleared fields do not recover stale values from older records. A retired variant cannot supply metadata to a current local record.

Optional `source_filters` hold creator/model/content-rating/orientation lists plus `min_short_edge`. Values within a field use OR; fields use AND. A section can inherit, `narrow` using both rule sets, `replace`, or opt out with `off`. Unknown metadata has an explicit empty-string choice; empty lists remain unrestricted. Filters constrain automatic/fixed/cycle assembly, scoped variations, manual assignment and accepted draft proposals. Existing playback/export stays valid; the library warns about placed regions outside current filters, and assembly requires incompatible kept clips to be unlocked. Folder and tag readiness counts use the same restrictions and shared metadata. Intensity, Civitai reaction counts and content-rating labels do not change scoring.

The searchable source dialog separates library-only browsing from saved session/section constraints, stages Apply/Cancel, preserves playback and shows unique matching/ready video counts. Clip details and library search include source information. A disposable import of the checksum-verified catalog at `54c92d0f63d78c4aad85ebce9bb32172196d2a0d` persisted all 151 records: 149 have creator metadata, spanning 48 creators and five named source models. No videos, scripts or credentials were fetched for that audit.

Composer's privileged services initially run in Electron's Node process, with the same JavaScript compiler imported by preview preparation and export. The inherited FastAPI service continues to serve FunSync. There is no additional REST server or websocket compiler protocol in this version.

The recipe uses integer milliseconds at section boundaries and script output, with floating-point source-rate mapping. Export quantizes absolute cut positions to 30 fps rather than accumulating rounded clip durations. The proposed microsecond/rational internal representation is future work.

Catalog and recipes use atomic JSON files rather than SQLite. This is suitable for the initial library size; library paging, a database index, a disk quota, and an eviction policy remain open. Saved recipes pin stat/script/variant bindings; playback fails clearly when those assets change, while offline and unresolved recipes remain saveable. HF script cache reuse follows content checksums, and retired variants remain addressable using their original commit. Historical local media bytes are not copied. See [the September audit fixes](AUDIT-FIXES-2026-09-22.md) for compatibility and validation.

The initial section proposal is six equal ranges. Audio analysis supplies waveform, tempo, confidence, and event data; automatic musical form labeling is not implemented. Source gaps are explicitly marked. Music & beats supports authored pattern blocks and optional drum-stem timing; sessions without music-editor settings retain the original tempo-aligned, energy-following sine generator.

The live ComfyUI editor and GPU extraction pipeline are not connected. Local saved sidecar scripts and dataset variants are supported inputs. Civitai media are checked for plausible duration, not cryptographic frame identity with a source video.
